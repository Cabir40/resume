# Career Portfolio Repository

This repository is prepared to showcase my career information in one place.

## Repository Structure

- `/cv` - resume/CV files
- `/diplomas` - diploma copies and transcripts
- `/certificates` - professional certificates and training records
- `/articles-thesis` - articles, thesis, and research documents
- `/blogposts` - career-related blog posts
- `/assets` - supporting images or other shared files

## Suggested File Naming

Use clear, searchable names, for example:

- `cv/cabir_resume_2026.pdf`
- `diplomas/bsc_computer_science.pdf`
- `certificates/aws_cloud_practitioner.pdf`
- `articles-thesis/master_thesis_machine_learning.pdf`
- `blogposts/2026-06-career-journey.md`

## Notes

- Keep sensitive personal data out of public files.
- Prefer PDF for finalized documents.
- Add updates over time to keep the portfolio current.
